## 1. Kriteria Partisipan Target (5 sampai 8 Orang Awam)

Partisipan yang diundang wajib memenuhi kriteria inklusi berikut:
1. Pengguna umum tanpa latar belakang pendidikan formal arsitektur, teknik sipil, atau perencanaan wilayah kota.
2. Memiliki keterampilan dasar mengoperasikan komputer desktop atau laptop dan peramban web modern.
3. Bersedia menjalankan tugas terpandu dengan metode berpikir bersuara (think aloud protocol).

## 4. Kuesioner System Usability Scale (SUS) Standar

Skala jawaban: 1 (Sangat Tidak Setuju) sampai 5 (Sangat Setuju).

1. Q1: Saya merasa akan sering menggunakan aplikasi ini untuk belajar arsitektur.
2. Q2: Saya merasa aplikasi ini terlalu rumit untuk dipahami orang awam. (Pertanyaan Negatif)
3. Q3: Saya merasa aplikasi ini sangat mudah digunakan.
4. Q4: Saya merasa membutuhkan bantuan teknis dari ahli untuk dapat menggunakan aplikasi ini. (Pertanyaan Negatif)
5. Q5: Saya merasa berbagai fitur dan tombol dalam aplikasi terintegrasi dengan sangat baik.
6. Q6: Saya merasa ada banyak hal yang tidak konsisten dalam aplikasi ini. (Pertanyaan Negatif)
7. Q7: Saya membayangkan kebanyakan orang akan cepat memahami cara memakai aplikasi ini.
8. Q8: Saya merasa antarmuka aplikasi ini membingungkan dan canggung. (Pertanyaan Negatif)
9. Q9: Saya merasa sangat percaya diri saat menjelajahi fitur aplikasi ini.
10. Q10: Saya harus mempelajari banyak hal baru sebelum saya dapat mulai merancang kota. (Pertanyaan Negatif)
